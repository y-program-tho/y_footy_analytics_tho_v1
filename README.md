# y_footy_analytics_tho_v1

y_footy_analytics_tho_v1 is a Python package for analyzing football data for players, teams and leagues. It provides data visualistaions and provide statistical analysis and insights to inform foootball lovers, enthusiasts and professionals within teh industry.
